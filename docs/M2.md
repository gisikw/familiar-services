# M2: scheduler

`familiar-services serve --socket /run/familiar-services/familiar.sock --attention-db PATH --state-dir PATH [--default-target SESSION_ID]` owns Attention and one SQLite scheduler at `STATE_DIR/scheduler.sqlite`.

## Model

An event is `{id, due_at, target, origin, source, priority, type, summary, body, state, created_at}`. `state` is `pending`, `delivered`, or `acked`; a caller-supplied `id` is a permanent deduplication key. A due-now notification and a future wake are identical. Targets are `instance:<Pi session id>` or `spawn:<systemd unit>`; spawn events are retained for M3 and are not delivered. The caller's `FAMILIAR_INSTANCE_ID` becomes `origin`, and target defaults to origin. With neither, the service uses `--default-target`, then the most recently connected instance.

DND is a per-instance scheduler hold. Due events remain queued while it is active and release when it clears or expires. DND set by Familiar is capped at two hours. Delivery is paced to at most one event per connected instance every 15 seconds, ordered by priority and due time; reconnect redelivery is immediate.

The socket uses newline-delimited JSON. Short-lived clients use `{op,args}` with `schedule.enqueue`, `schedule.list`, `schedule.cancel`, `dnd.get`, and `dnd.set`. A Pi keeps one connection open, sends `{"op":"hello","args":{"instance":"SESSION_ID"}}`, and receives `{"event": EVENT}`. It injects each event and replies with `schedule.ack`. Delivered-but-unacked events return on reconnect; Pi also deduplicates injected IDs.

Agent operations are `imp schedule --in 30m|--at TIME [--target instance:ID|spawn:UNIT] REASON`, `imp schedule list`, `imp schedule cancel ID`, `imp notify REASON`, and `imp dnd [on DURATION|off|status]`.

## Cutover

1. Stop every Pi and all old writers. Back up the state directory, including SQLite `-wal` and `-shm` files.
2. Copy the live file stores only for testing if desired; never test against `/var/lib/kestrel/state/{worklist,wakes}` directly.
3. Run `familiar-services migrate --state-dir PATH --default-target SESSION_ID`. This idempotently imports live `worklist/items/*.json` and `wakes/pending/*.json`; archived and fired records stay historical.
4. Start `serve` with the same state directory and optional default target. Start the new Pi extension and verify its hello, push, injection, and ack.
5. Remove the old file-store writers. Do not dual-write. Rollback requires freezing delivery before restoring the backup.
